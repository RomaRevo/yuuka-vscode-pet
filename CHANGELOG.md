# Changelog

## 1.3.1

- Delay mouse observation until the pointer rests briefly, avoiding immediate turns
  during ordinary movement.
- Add a regression test for the dwell behavior.

## 1.3.0

- Add configurable save, typing, idle, focus, and VS Code Task reactions.
- Add head pats, pokes, horizontal drag placement, jump, think, and milestone actions.
- Add contextual dialogue, local mood and affinity, and low-frequency character events.
- Keep editor, terminal, Git, and network content outside the extension's runtime access.
