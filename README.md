# Yuuka VS Code Pet

独立的早濑优香 VS Code 桌宠扩展。1.4.0 在 V8 Q 版像素动画的基础上加入专注计时、今日任务、提醒、统计、关系设置和主题场景；扩展不依赖 VS Code Pets 或 Codex Pets。

## 安装

1. 从 [GitHub Releases](https://github.com/RomaRevo/yuuka-vscode-pet/releases/tag/v1.4.0) 下载 `yuuka-vscode-pet-1.4.0.vsix`。
2. 在 VS Code 中运行 `Extensions: Install from VSIX...`。
3. 选择 VSIX，安装后运行 `Developer: Reload Window`。

也可以在终端安装：

```text
code --install-extension yuuka-vscode-pet-1.4.0.vsix
```

当前扩展版本：`1.4.0`。完整变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

安装后点击活动栏中的“优香桌宠”图标，打开 `早濑优香` 视图。主区域显示桌宠和台词，下方按钮提供互动、工作和位置复位。

- 点击头部：摸头，会影响本地心情/好感。
- 点击身体：轻戳，连续快速操作会触发冷却和生气反馈。
- 点击地面：让优香走到指定位置。
- 拖动优香：调整桌宠位置。
- 鼠标停留：只有短暂停留后才会观察鼠标方向，普通滑动不会立即转身。
- `Enter` 或空格：执行一次互动。

“工作”状态会锁定位置并播放工作动画。工作期间点击地面或优香只会短暂显示生气反馈，不会移动或解除工作锁定；点击“互动”或“复位”可以退出工作状态。

## 生产力工具

生产力区域分为“专注、任务、提醒、统计、关系、场景”六个页签。

### 专注计时

- 默认专注 `25` 分钟、短休息 `5` 分钟、长休息 `15` 分钟。
- 支持开始/继续、暂停、结束和重置。
- 每完成设定轮数后自动进入长休息。
- 计时由扩展宿主维护；隐藏或重开桌宠视图不会丢失计时状态。
- 专注期间优香进入工作锁定；完成后播放庆祝并更新统计。

### 今日任务

- 添加、完成、删除任务，并选择当前专注任务。
- 任务只保存在当前工作区，不读取仓库 TODO、源码或文件名。
- 同一任务只计入一次完成统计。

### 提醒

- 支持用户主动创建一次性提醒。
- 可选喝水提醒和整点提醒；循环提醒默认关闭。
- 支持跨午夜静默时段，静默期间到期的提醒会在静默结束后处理。
- 同一时刻多个提醒会合并，避免连续弹出打扰。

### 统计

显示今日/本周专注次数、专注分钟、完成任务数和连续专注天数，并提供清除本机统计入口。统计只保存日期和数字，不保存任务文字或提醒文字。

## 关系与场景

“关系”页支持五档心情（很开心、开心、平静、低落、很低落）和 `0–100` 整数好感，可用滑块或数字框设置，也可关闭关系系统或重置为平静/`0` 好感。关系值只影响低频台词、互动动作和待机动作。

“场景”页提供简洁办公室、千年风格和纯透明感三种本地背景。办公室背景匹配 `72×78` 逻辑帧与 `2×` 显示倍率，颜色随 VS Code 深色/浅色主题适配。

## VS Code 联动与设置

扩展支持保存、连续输入、编辑器空闲、重新聚焦、VS Code Task 退出码和显式里程碑反馈；不读取源码、文件名、终端输出或 Git 内容。随机预算/计划事件仅在空闲时低频出现。

在 VS Code Settings 搜索 `Yuuka VS Code Pet`，可配置联动冷却、任务反馈、随机事件、关系开关、场景、专注/休息时长、长休息间隔、循环提醒和静默时段。命令面板还提供 `Start or Resume Focus`、`Pause Focus`、`Reset Focus Timer` 和 `Clear Focus Statistics`。

## 隐私

扩展运行时不访问网络，不读取项目源码、文档内容、文件名、工作区路径、终端文本或 Git 提交内容，不收集或上传数据，也不会自动执行任务、提交或修改 Git。任务、提醒和计时器按工作区保存；全局统计只保存日期和数字；心情、好感、场景和开关保存在本机状态或设置中。

详细说明见 [PRIVACY.md](PRIVACY.md)。

## 本地开发

```text
npm run check
python build_vsix.py
```

`npm run check` 执行 JavaScript 语法检查和完整 Node 测试。
